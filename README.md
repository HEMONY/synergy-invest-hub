# Synergy Invest Hub

🎯 نظرة عامة على المشروع

أنشئ منصة ويب احترافية متكاملة باسم "Synergy" — منصة وساطة استثمارية عقارية تربط بين أصحاب العقارات المتضررة و المستثمرين/الممولين، مع طرف ثالث وسيط وهو الإدارة والمشرفين الذين يديرون كامل العملية.

الفكرة التجارية (User Flow الكامل)

صاحب العقار المتضرر: يُنشئ حساباً، يرفع مستند هوية رسمي + وثيقة ملكية العقار، وينتظر مراجعة الإدارة.

المستثمر/الممول: يُنشئ حساباً، يرفع مستند هوية رسمي (إثبات مالي/هوية)، وينتظر مراجعة الإدارة.

الإدارة/المشرفون: يراجعون المستندات المرفوعة ويوافقون عليها → يتحول الحساب إلى "حساب موثّق" (Verified) مع شارة توثيق ظاهرة على الحساب.

صاحب العقار الموثّق يرفع طلب تمويل لعقاره المتضرر (تفاصيل الطلب أدناه) → يظهر الطلب في صفحة "الفرص" للمستثمرين الموثقين فقط.

المستثمر يتصفح الفرص، يفلتر حسب المعايير، ويختار طلباً يناسبه ثم يضغط "أريد الاستثمار / تمويل هذا الطلب".

عند قبول المستثمر للطلب، يصل إشعار للمشرف/الإدارة لمراجعة عملية الربط.

المشرف يتواصل مع الطرفين كوسيط، يستلم مبلغ التمويل من المستثمر (أو يوثق تحويله)، ثم يديره كمرحلة "مشروع قيد التنفيذ" حتى اكتمال إعادة تأهيل العقار.

طوال العملية، تتحدث نسبة الإنجاز وحالة المشروع ويصل إشعار للطرفين بكل تحديث.

🎨 الهوية البصرية (يجب الالتزام بها حرفياً)

الشعار

شعار Synergy: حرف S مصمم بأسلوب هلالين متشابكين — الجزء العلوي/الأيسر باللون الكحلي الداكن (Navy) والجزء السفلي/الأيمن باللون الذهبي (Gold)، وفي المنتصف مبانٍ/أبراج ذهبية اللون ويدان تتصافحان (باللونين الكحلي والذهبي) ترمزان للشراكة بين الطرفين. اسم "SYNERGY" أسفل الشعار بخط كحلي داكن متباعد الأحرف (letter-spacing واسع)، بأحرف كبيرة (Uppercase).

استخدم شعاراً بهذا المفهوم بالضبط: دائرة/هلال متشابك بحرف S + مبانٍ + مصافحة يدين بألوان كحلي وذهبي، قابل للاستخدام في نسخة فاتحة (للـ Light Mode) ونسخة يظهر فيها بوضوح على خلفية داكنة (للـ Dark Mode).

الألوان الرئيسية (استخدم هذه القيم بالضبط)

الكحلي الداكن (خلفية Dark Mode / نص Light Mode): #0D1B2A

الكحلي المتوسط (عناصر ثانوية / بطاقات في Dark Mode): #142A4A

الذهبي الأساسي (أزرار أساسية، تمييز): #D4AF37

الذهبي الفاتح (تدرجات، Hover): #F1C86A

الأبيض/الرمادي الفاتح جداً (خلفية Light Mode): #F5F6F8

الوضعان

Dark Mode: خلفية #0D1B2A، بطاقات بلون #142A4A، أزرار أساسية ذهبية #D4AF37، نص أبيض/رمادي فاتح.

Light Mode: خلفية #F5F6F8 وأبيض نقي، عناوين ونصوص بلون كحلي #0D1B2A، أزرار أساسية كحلية مع تفاصيل ذهبية، وأزرار ثانوية ذهبية.

زر تبديل بين الوضعين ثابت وظاهر في الـ Navbar (أيقونة شمس/قمر).

الخط

استخدم خط Cairo (Google Font) في كامل الموقع — خط عربي عصري وواضح ويدعم الأرقام. تأكد من دعم RTL كامل لكل الموقع (اتجاه من اليمين لليسار)، مع دعم مزدوج للعربية والإنجليزية إن أمكن.

الأيقونات

أيقونات بسيطة بخطوط نظيفة (outline/line icons) بنفس الألوان (ذهبي على الداكن، كحلي/ذهبي على الفاتح): منزل (الرئيسية)، رسم بياني (الفرص/الاستثمار)، حقيبة (طلباتي)، جرس (الإشعارات)، شخص (الحساب).

الأسلوب العام

تصميم فخم واحترافي "Fintech/PropTech premium" — بطاقات بحواف دائرية ناعمة، ظلال خفيفة، مساحات بيضاء/تنفس جيدة، تدرجات ذهبية خفيفة على الأزرار الأساسية، أيقونات SVG نظيفة، Micro-interactions ناعمة عند الـ Hover، وتصميم متجاوب بالكامل (Responsive) لأجهزة الجوال والحاسوب.

نسبة الإنجاز (Progress Bar واضح لكل مشروع)

🔔 الإشعارات

مستنداتي (رفع/عرض حالة توثيق المستندات: قيد المراجعة/موثّق/مرفوض مع سبب الرفض)

مدفوعاتي (سجل التحويلات المالية والعمولات إن وجدت)

الدعم (نموذج تواصل / تذاكر دعم فني)

🛠️ لوحة تحكم المدير والمشرفين (Admin & Supervisor Dashboard)

أنشئ لوحة تحكم شاملة ومنفصلة بتصميم احترافي (Dashboard UI مع Sidebar + إحصائيات) تشمل:

إدارة المستخدمين

عرض كل الحسابات (أصحاب عقارات / مستثمرين / مشرفين)

مراجعة والموافقة/رفض مستندات التوثيق (هوية + وثيقة عقار) مع سبب الرفض

تفعيل/تعليق/حظر أي حساب

نظام صلاحيات (Roles & Permissions) يسمح للمدير بإنشاء مشرفين وتحديد صلاحيات كل مشرف بدقة (مثلاً: مشرف مسؤول عن التوثيق فقط، مشرف مسؤول عن المشاريع فقط، مشرف مالي، Super Admin بصلاحيات كاملة)

إدارة الطلبات والفرص

عرض جميع طلبات العقارات المتضررة (قيد المراجعة / معتمدة / مرفوضة)

الموافقة على نشر الطلب في صفحة "الفرص"

تعديل أو إخفاء أي طلب

إدارة الربط والوساطة المالية

عند قبول مستثمر لطلب: تظهر للمشرف عملية ربط جديدة يتابعها خطوة بخطوة (توثيق استلام المبلغ من الممول → صرفه لصاحب العقار → متابعة التنفيذ)

سجل كامل للتحويلات المالية بين الطرفين مع إمكانية رفع إيصالات/إثباتات تحويل

إدارة المشاريع الجارية

تحديث حالة كل مشروع ونسبة الإنجاز يدوياً من قبل المشرف المسؤول

إضافة تحديثات/صور تقدم للمشروع تصل كإشعار لصاحب العقار والمستثمر

التقارير والمراقبة

لوحة إحصائيات عامة (عدد المستخدمين، عدد الطلبات، إجمالي التمويل، المشاريع الجارية والمكتملة) بالرسوم البيانية

سجل نشاطات (Audit Log) لكل إجراء يقوم به أي مشرف أو مدير

إدارة تذاكر الدعم الفني الواردة من المستخدمين

⚙️ المتطلبات التقنية

الواجهة الأمامية (Frontend): React + Tailwind CSS، خط Cairo، دعم RTL كامل، Responsive بالكامل (جوال/تابلت/حاسوب)، Dark/Light Mode بالتبديل الفوري.

الخادم الخلفي (Backend): Node.js (Express) مع REST API منظم، ونظام مصادقة JWT، وأدوار مستخدمين (Owner, Investor, Admin, Supervisor) بصلاحيات مختلفة (Role-Based Access Control).

قاعدة البيانات: MySQL، مع جداول واضحة تشمل على الأقل: users، documents (مستندات التوثيق)، properties (طلبات العقارات)، investments (عمليات الربط/التمويل)، projects (المشاريع الجارية وحالتها ونسبة إنجازها)، transactions (السجل المالي)، notifications، support_tickets، admin_permissions.

رفع الملفات (صور العقار، مستندات التوثيق) مع معاينة، ودعم أكثر من صورة لكل عقار.

نظام إشعارات داخلي فوري (In-app notifications) لكل تحديث في الطلب أو المشروع.

صفحة تسجيل دخول/تسجيل حساب أنيقة تفرّق بين نوع الحساب (صاحب عقار / مستثمر) من البداية، مع خطوة رفع المستندات كجزء من التسجيل.

✅ ملاحظة أخيرة

اجعل التصميم بأكمله متسقاً مع صور الهوية المرفقة (الشعار، الألوان، شكل البطاقات، الأزرار، الأيقونات، وتصميم نسخة الجوال)، بحيث يبدو الموقع منتجاً حقيقياً جاهزاً للإطلاق التجاري، لا نموذجاً أولياً.  وهذه صور لتسيق والوان الموقع والشعار
